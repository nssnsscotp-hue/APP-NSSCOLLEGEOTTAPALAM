## 🚀 How to Host on GitHub Pages (Direct Push Ready)

1. Create a new GitHub repository: `https://github.com/new` (e.g. `nss-college-app-privacy`).
2. Run these commands from your local computer terminal:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/nss-college-app-privacy.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Navigate to **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **GitHub Actions**.
4. That's it! The included `.github/workflows/deploy.yml` workflow will automatically build Vite and deploy the site live to GitHub Pages.
